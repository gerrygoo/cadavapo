# Director-role project provenance

**Delivery format:** every clip ships as a `<name>.webm` + `<name>.jpg`
poster + `<name>.placeholder.txt` trio (see
`docs/specs/2026-08-02-video-ingestion.md`). Run
`python3 scripts/generate-video-variants.py <path-to-source>` to generate
the set from a raw source — don't hand-add converted files.

**Source of truth:** Dani's portfolio Google Doc ("portafolio texto plano
danivponce.xyz", id `1VBSueYSDK-AJa_-UXKdlnAokAjP1DQ-39GDHIjwkJOk`) for
credits/titles, and the shared Drive folder "DANIVPONCE.XYZ" →
`DIRECTOR/` (id `1riENnPT0lxJPgSajBJx6jJ5mAsw4oG7M`) for raw footage — see
`docs/specs/2026-08-02-video-ingestion.md` for the full folder-ID map.
As of 2026-08-02, `erade-kafi/`, `hoy-erandi/`, and `westbound-khameleon/`
are fully ingested; `fantasma-astral/` and `satelite-futura-club/` are
partially ingested (some source GIFs exceed the Drive MCP download tool's
per-file limit); `presa-alamo-paraiso/`, `heroes-vicente-jauregui/`, and

`docs/plans/2026-08-02-director-role-and-video-sync.md`'s per-file status

## Archivo Digital (`archivo-digital/`)

- Source: https://www.youtube.com/watch?v=jx4Nt1Iv41k
- Non-fiction exploration, 4'40"
- Directed by: Dani Ponce
- Produced by: Biquini Wax EPS
- Edited by: Azael Arroyo y Daniela V. Ponce
- Sound design: Mónica Burciaga
- Archive material: *Videodanza viva videodanza* (1979, Pola Weiss),
  *Fragmento de nota manuscrita* (ca. 1962, Pola Weiss), *Neon Genesis
  Evangelion* — episode 20, "El Espejo del Alma"
- Sinopsis: Pieza pandémica audiovisual sobre el internet, los archivos de
  la memoria en el siglo XXI, todo hecho con material de archivo personal y
  que encontré en internet.
- Atizapán de Zaragoza, EDOMEX, 2020
- Note: the Drive source for this project is 7 raw GIFs (16–65MB each),
  not pre-compressed webm like the other 8 DIRECTOR projects — the one
  folder that actually needs the video-variants script's transcoding.

- Source: not linked in the portfolio doc — TBD, confirm with Dani.

- Directed by: Dani Ponce & Mauricio Sánchez
- Sinopsis: A través de la reapropiación de material de archivo, Daniela y

  reestructurar las realidades que conocemos.
- CDMX, 2020
